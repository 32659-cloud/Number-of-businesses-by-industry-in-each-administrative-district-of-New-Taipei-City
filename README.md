# 新北市各行政區商業行業別家數

互動式圖表：新北市 29 個行政區 × 20 個行業別的商業家數（民國 115 年 6 月，單月）。

網頁：`docs/index.html`（可用 GitHub Pages 發布，來源選 `main` 分支的 `/docs` 資料夾）

## 資料來源

- [新北市商業各行政區行業別家數](https://data.gov.tw/dataset/124937)，政府資料開放平臺 data.gov.tw
- 提供機關：新北市政府經濟發展局；更新頻率：每月；授權：政府資料開放授權條款－第 1 版
- 欄位：`section` 行政區、`industry` 行業別、`quantity` 家數（單位：家）、`date` 蒐集年月（民國年月，`11506` = 2026-06）

## 專案結構

| 路徑 | 內容 |
|---|---|
| `data/raw/` | 原始檔，從來源下載後未修改 |
| `etl/etl.py` | ETL：讀取、清理、驗證、輸出（只用 Python 標準函式庫） |
| `data/processed/` | ETL 輸出：`district_industry.csv`（明細＋占比＋集中度）、`district_totals.csv`、`industry_totals.csv`、`validation_report.txt` |
| `docs/` | 網頁：`index.html` 與 ETL 產生的 `data.js` |

重新產生處理後資料與 `docs/data.js`：

```bash
python etl/etl.py
```

## ETL 做了什麼

- 民國年月轉西元（`11506` → `2026-06`）。
- 名稱更正：「電子及燃氣供應業」→「電力及燃氣供應業」（原始資料筆誤）；「公共行政及國防;強制性社會安全」分號改全形。原始名稱保留在 `industry_raw` 欄。
- 驗證（失敗會直接中止，不產出檔案）：
  - 行政區剛好是官方 29 區；
  - 沒有重複的（區、行業、月）；
  - 筆數 = 29 × 20 × 1 = 580，沒有缺格；
  - 各區加總 = 各行業加總 = 逐列逐欄加總 = 全市 152,372 家。
- 衍生欄位：`share_in_district_pct`（占該區比例）、`share_in_city_pct`（占全市比例）、`lq`（集中度 = 區內占比 ÷ 全市占比）。

## 限制

- 只有單月資料，不能判斷趨勢。
- 「公共行政及國防；強制性社會安全」「醫療保健及社會工作服務業」「未分類」29 區全部為 0，可能不在統計範圍或原始資料缺漏，無法判斷。
- 資料集未說明「家數」的口徑（登記數或營業中、是否含公司登記），以來源機關說明為準。
- 占比與集中度是本專案計算的結果，不是來源欄位。
